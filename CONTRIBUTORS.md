# Contributors and attribution

This repository is not an independent reimplementation. It continues development directly on the original [YouTube Digest](https://github.com/zarazhangrui/youtube-digest) project created by [Zara Zhang (@zarazhangrui)](https://github.com/zarazhangrui). The complete upstream Git history is retained so authorship remains visible and auditable.

## Original project

- [Zara Zhang (@zarazhangrui)](https://github.com/zarazhangrui) created YouTube Digest and maintains the upstream project. The original MIT copyright notice remains unchanged in `LICENSE`.
- See the upstream project's complete [Contributors graph](https://github.com/zarazhangrui/youtube-digest/graphs/contributors). Git may show several commit-name or email aliases for the same original author.

Its assistance is recorded explicitly in this file, `NOTICE.md`, the README credit tables, and `Assisted-by` commit trailers.

Additional contributors remain credited through the preserved commit history and GitHub Contributors graphs. Future human contributors should use their own verified Git identity so GitHub can attribute their commits correctly.
